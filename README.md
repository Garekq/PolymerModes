# PolymerModes — автоматизированный подбор режимов FFF

Рабочий прототип инженерного инструмента для Windows. Репозиторий содержит исходный код; готовая сборка EXE в него не включена. Установите Python 3 с Tkinter и запустите `py -3 app.py` или `Запуск.bat`. Для сборки EXE установите PyInstaller (`py -3 -m pip install pyinstaller`) и запустите `build.bat`; после сборки открывайте `dist\PolymerModes\PolymerModes.exe`, сохраняя всю папку вместе. Данные создаются в `%LOCALAPPDATA%\PolymerModes\polymer.sqlite3`; для резервной копии закройте приложение и скопируйте базу.

Выберите материал и оборудование, задайте геометрию и температуры, выполните проверку. Профили поставщика — примеры, а не сведения о предприятии. Профиль редактируется на вкладке библиотеки по полям или в JSON: отсутствующее значение обозначается `null`; `brand_confirmed` устанавливается в `true` пользователем только после сверки партии. Диапазоны в профилях отражают текст карточек производителя, а не гарантию безопасной комбинации. Если температурные окна отсутствуют или марка не подтверждена, выводится статус недостаточности данных. Результат не является подтверждённой технологией.

При переносе кнопка показывает характеристики исходного и целевого принтеров, пересчитывает скорость по сохранению расхода и проверяет целевую конфигурацию. Исходный режим и остальные настройки, включая ретракт, пользователь проверяет самостоятельно. На вкладке истории выберите сохранённый расчёт и добавьте протокол с измерениями и собственными критериями; протокол можно сохранить в HTML или JSON. Пустые измерения и критерии не считаются выполненными. Кнопка плана испытаний учитывает выбранный приоритет. HTML, JSON и CSV — диагностические файлы, не профили слайсеров и не G-code. Импорт и экспорт Cura/Orca доступны с ограничениями, описанными в инструкции по обмену. См. PROGRESS.md для полного перечня ограничений.

Тесты: `python -m unittest discover -s tests -v`. Сборка при установленном PyInstaller: `build.bat`; комплект создаётся в `dist\PolymerModes`. На практике доступны не все пункты ТЗ — см. протокол и журнал.

Вкладка «Литературные экспериментальные данные» содержит опубликованные сторонние режимы и результаты. Выбор записи показывает источник и исходные условия; при известной ширине линии кнопка демонстрирует расчётный перенос расхода. Детали и границы применения: `docs\ЛИТЕРАТУРНЫЕ_ДАННЫЕ.md`.

## Обмен профилями Cura и OrcaSlicer

На вкладке «Cura / OrcaSlicer» доступны ограниченный импорт и экспорт через целевой шаблон. Перед использованием прочитайте `docs\ОБМЕН_СЛАЙСЕРАМИ.md`: там описаны обязательные данные и ограничения. Проверены отдельные сценарии импорта в Cura 5.14.0 и OrcaSlicer 2.5.2; профиль остаётся предварительным.


## Дополнительные условия и повторные испытания

На вкладке «Доп. параметры» вводятся скорости отдельных элементов, подача, ретракт, ускорение, обдув, заполнение, ориентация, адгезия и условия сушки. Пустые поля остаются неизвестными. Значения сохраняются в расчёте как введённые пользователем и показываются в отчёте, но их технологическая совместимость автоматически не проверяется и в файлы слайсеров они не записываются.

Для отметки о подтверждении сначала сохраните расчёт и создайте для него не менее двух протоколов повторных испытаний. У каждого укажите уникальный номер образца; партия, тип и ориентация образца, методика, сушка и остальные условия должны совпадать, как и заданные критерии. Выберите исходный расчёт в истории, нажмите «Подтвердить по повторам», выберите протоколы и подтвердите достоверность результатов и выполнение отдельных повторных печатей. Программа проверяет численные критерии и исходный режим, но не может удостовериться, что печать действительно выполнялась и что количество повторений достаточно для конкретного применения. Сохранённая отметка относится только к указанным материалу, оборудованию, параметрам и критериям; изменение профиля не делает новую конфигурацию проверенной. Старые протоколы без идентификатора расчёта нужно занести заново для включения в серию. При экспорте в слайсер профиль по-прежнему маркируется как предварительный.

При известном Qmax в профиле принтера задайте также `qmax_material` (точное имя материала), `qmax_nozzle_diameter` (мм) и `qmax_temperature` (°C). Расчёт скорости по Qmax и сравнение расхода выполняются только при совпадении всех трёх условий с выбранным режимом. Без них Qmax не используется и производительность остаётся непроверенной.

## Библиотека и происхождение данных

В разделе «Библиотека» выберите материалы или принтеры, затем нажмите «Изменить поля» либо «Новый по полям». В открывшейся форме выберите характеристику, введите значение и укажите происхождение: справочное, введённое пользователем, расчётное или экспериментальное. Для справочного значения обязательно укажите конкретный источник. Пустое поле означает неизвестное значение. В просмотре профиля источник и происхождение показываются отдельно для каждой заполненной характеристики.

У ранее созданных профилей происхождение отдельных полей может быть не указано: общий источник профиля не присваивается полям автоматически. При изменении критических данных материала или их источника подтверждение марки сбрасывается. После сверки паспорта партии пользователь может отдельно установить «Марка и паспорт подтверждены» в «Да» с происхождением «введён пользователем».

Расширенный редактор JSON сохранён. При изменении в нём значения связанное со старым значением происхождение удаляется; его следует заново задать через форму. Поля, не поддерживаемые формой, при редактировании по полям сохраняются. Запись источника пользователем не означает, что программа проверила содержимое документа или его применимость к партии.
