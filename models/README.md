# Контрольные модели

STL в этой папке — условные геометрические образцы в миллиметрах: куб 20×20×20 для размеров и пластина 80×20×3 для наблюдения коробления. Они не являются стандартными образцами для растяжения или изгиба. Одностенный тест можно подготовить в слайсере из куба: одна стенка, без заполнения и верхних слоёв; проверить конфигурацию на предпросмотре. Подтверждения геометрической точности производства и механических свойств нет. Исходник `tools/make_models.py` позволяет менять размеры. Стандартные механические образцы должны быть подготовлены по применимой редакции стандарта и требованиям испытательной лаборатории.
